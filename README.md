# Ajudar Bem - Projeto WEB


Projeto simples desenvolvido como parte da entrega final da disciplina. O objetivo é demonstrar conhecimentos em HTML, CSS, JavaScript, Git, GitHub, Acessibilidade (WCAG 2.1) e Deploy.


## 📌 Funcionalidades
- Navegação acessível por teclado
- Modo de alto contraste
- Estrutura semântica
- Formulário de contato acessível
- Imagens com texto alternativo


## 🧩 Estrutura do Projeto
```
/ajudar-bem
├── index.html
├── sobre.html
├── contato.html
├── css/estilo.css
├── js/script.js
├── imagens/
├── README.md
```
